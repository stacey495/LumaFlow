# LumaFlow

LumaFlow зменшує цифровий шум на зображеннях медіанним фільтром і підсилює контури. У браузері можна стежити за прогресом, порівняти зображення до й після обробки та завантажити результат у JPG.

## Запуск на Windows

Потрібен Python 3.12 або новіший. Під час першого запуску скрипт за потреби створює віртуальне середовище й установлює залежності з PyPI.

| Режим | Запуск |
|---|---|
| Локальні сервери | Двічі клацніть `Start-LumaFlow.cmd`. |
| Docker | Запустіть Docker Desktop у режимі Linux-контейнерів із WSL 2, а потім двічі клацніть `Start-LumaFlow-Docker.cmd`. Під час першого запуску скрипт збере образ. |

Після запуску відкриється `https://localhost:8443`. Для обробки зображень створіть акаунт через **Реєстрацію**. Дані для входу локального адміністратора створюються під час першого запуску й зберігаються в `.runtime/admin.json`.

## Як працює

Вебсервер приймає файли JPG, PNG і WebP розміром до 10 МБ і 6 Мп. Планувальник бере задачі з черги FIFO та розподіляє їх за методом Least Loaded, де навантаження визначає кількість активних задач. Результати й історія зберігаються в SQLite.

У режимі Docker працюють два базові контейнери. Під навантаженням планувальник може додати ще два. У вкладці **Моніторинг** адміністратор бачить стан серверів, чергу та використання ресурсів.
